# 첫칸

노베이스 수능생이 오늘 해야 할 공부를 한 칸씩 시작하도록 돕는 모바일 우선 학습 코치입니다.

## 주요 기능

- 국어·영어·수학 오늘 할 일과 완료 진도
- 기초 → 기본 → EBS 연계 과목별 로드맵
- 처음부터 보는 핵심 개념 카드
- 5개 필수 영단어 플래시카드와 암기 상태
- EBSi 수능개념·수능 빌드업·수능특강 Light 공식 연결
- 25분 집중 타이머, 최근 7일 기록, 연속 학습
- 이름·일일 목표·학습 진행 상태의 기기 내 자동 저장

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm ci
npm run dev
```

## 검증

```bash
npm run lint
npm run typecheck
npm test
```

## 데이터와 범위

첫 버전은 회원가입이나 서버 동기화가 없는 로컬 우선 MVP입니다. 학습 기록은 브라우저의 `localStorage`에 저장되므로 같은 브라우저·기기에서 유지됩니다. EBS 강의와 교재는 복제하지 않고 EBSi 공식 페이지를 새 탭으로 연결합니다.
