# 수능人

`수능人`은 고1 기초 수준에서 시작해 2028학년도 수능까지 이어지는 국어·영어·수학 모바일 학습 코치입니다. 기본 사용자는 `인1이`이며, 파트너 `능이`가 오늘의 가장 쉬운 한 칸과 3분 시작을 안내합니다.

## 주요 기능

- 2028학년도 수능일(2027년 11월 18일)까지 남은 D-day
- 틀려도 차감되지 않는 성장 포인트·레벨과 응원 파트너 `능이`
- 국어·영어 12주 기초 로드맵과 오늘 할 일 체크
- 국어: 읽기 기초 → 독서/비문학 → 문학 → 언어 → 화법/작문/매체 → 문제 적용/EBS 지식 지도
- 영어: 어휘/발음 → 듣기 → 문장 문법 → 구문 독해 → 독해 유형 → EBS/실전 지식 지도
- 수학: 수와 연산 → 문자와 식·방정식 → 함수 → 도형 → 경우의 수·확률 → 고교 공통수학 연결 지식 지도
- 각 세부 개념의 선수 개념, 핵심 포인트/공식, 30~60분 루틴, 통과 기준, 문제와 즉시 해설
- `again / hard / good / easy` 평가를 쓰는 46개 단어 SRS 복습과 10개 학습 세션
- 새 단어 / 학습 중 / 복습 예정 / 완료 상태, 즐겨찾기, 검색·필터 가능한 내 단어장
- EBSi 공식 공통국어·공통영어·공통수학 입문 강의 및 과목별 페이지 연결
- 3·15·25·50분 집중 타이머, 최근 7일 기록, 연속 학습, 이름·한 줄 목표 저장

## 실행

Node.js `22.13` 이상이 필요합니다.

```bash
npm ci
npm run dev
```

## 검증

```bash
npm run typecheck
npm run lint
npm test
```

## 로컬 저장

- 진도, 문제, 단어 복습, 타이머 기록은 브라우저 `localStorage`의 `first-step-study-v2` 키에 저장됩니다.
- 예전 버전 데이터가 있으면 `first-step-study-v1`에서 안전하게 마이그레이션합니다.
- 서버 계정 동기화는 없으므로 같은 브라우저·기기에서만 기록이 유지됩니다.
- EBS 강의와 교재 본문은 복제하지 않고 EBSi 공식 페이지를 새 탭으로 연결합니다.

## 범위

현재 버전은 로컬 우선 MVP입니다. 고1 노베이스 학습자가 부담 없이 시작하고, 국영수 기본기를 반복 가능한 학습 루프로 만드는 데 초점을 둡니다. 실제 응시 전에는 해당 연도 평가원 시행계획과 학교 과목 편성을 다시 확인하세요.
